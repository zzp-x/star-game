## 相机（改为「绝对不要再动」的一组）

| 参数 | 值 | 为什么锁死 |
| --- | --- | --- |
| 俯角 | −52° | 改动会让格子与屏幕不再轴对齐，鼠标点选立刻变难 |
| FOV | 40° | 低 FOV 削弱边缘透视变形；调大低模场景会显出"很扁" |
| 偏航步进 | 90° | 非 90° 会让格子变菱形，交互复杂度陡增 |
| 初始距离 | 18 m | 玩家可滚轮缩放到 10–28 |
